# 📋 Life Management System

A console-based Python application that helps you organize everyday records in one place. This project was built to solve a real-life problem while improving my Python programming and object-oriented programming (OOP) skills.

---

## 🚀 Features

- 💰 Manage borrowed and lent money
- 📦 Keep track of borrowed and lent items
- 🧾 Store bill names, due dates, and amounts
- ✏️ Delete records when no longer needed
- 📄 Display all saved records in a single view
- 🖥️ Interactive terminal-based user interface

---

## 🛠️ Technologies Used

- Python
- Object-Oriented Programming (OOP)
